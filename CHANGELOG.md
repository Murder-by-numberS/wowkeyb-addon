# Changelog

## 1.1.0

- **Action bar support** – Spells are now placed on action bars (default WoW UI)
- Uses `PlaceAction` + `SetBinding` instead of `SetBindingSpell` so spells appear on bars
- Slot mapping: 1–12 = main bar, SHIFT+1–12 = bar 2, letter keys = bar 5

## 1.0.0 (Initial Release)

- Import keybinding profiles from WoWKeyb (wowkeyb.gg)
- Apply profiles with `/wowkeyb apply`
- Toggle between last two profiles with `/wowkeyb toggle`
- Switch profiles with `/wowkeyb switch`
- List, import, and delete stored profiles
