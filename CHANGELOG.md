# Changelog

## 1.2.94

- Switch between the keybind map and Profiles from the Map / Profiles control in the addon window.

## 1.2.93

- Left-click the minimap icon to open the keybind map. Right-click to open profiles.
- Profile actions sit on the profile you select: apply, view, export, duplicate, rename, reset, and delete.

## 1.2.92

- Browse imported profiles in game. Search, and filter to this character or other classes.
- Open it with `/wowkeyb profiles`, **Browse Profiles** in addon settings, or middle-click the minimap icon.

## 1.1.0

- **Action bar support** – Spells are now placed on action bars (default WoW UI)
- Uses `PlaceAction` + `SetBinding` instead of `SetBindingSpell` so spells appear on bars
- Slot mapping: 1–12 = main bar, SHIFT+1–12 = bar 2, letter keys = bar 5

## 1.0.0 (Initial Release)

- Import keybinding profiles from WoWKeyb (wowkeyb.gg)
- Apply profiles with `/wowkeyb apply`
- Toggle between last two profiles with `/wowkeyb toggle`
- Switch profiles with `/wowkeyb switch`
- List, import, and delete stored profiles
